# 入社手続きチェックリスト

最終更新: 2026-05-20 / 人事部

## 初日

- [ ] 入館証の受け取り（1F 受付）
- [ ] PC の受け取りと初期設定
- [ ] 社内アカウント（SSO）の有効化
- [ ] Slack への招待を受ける

## 3日以内

- [ ] Workflow（経費精算・各種申請）のアカウント発行を申請
- [ ] 交通費の定期区間を登録
- [ ] 緊急連絡先の登録

## 1ヶ月以内

- [ ] 情報セキュリティ研修の受講（必須・オンライン）
- [ ] ハラスメント防止研修の受講（必須）
- [ ] メンターとの1on1を2回実施

## Workflow アカウントについて

発行には 2〜3 営業日かかります。発行されるまでの経費は
立て替えておき、発行後にまとめて申請できます。
締め切りの扱いは「経費精算ルール」を参照してください。
