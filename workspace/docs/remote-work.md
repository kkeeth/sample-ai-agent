# リモートワーク規程

最終改定: 2026-02-15 / 人事部

## 対象

入社3ヶ月を経過した正社員および契約社員。試用期間中の社員は
原則出社ですが、上長の判断で例外を認める場合があります。

## 日数の上限

週3日まで。月初に Workflow から翌月分をまとめて申請します。
申請なしの在宅勤務は欠勤扱いになるので注意してください。

## コアタイム

11:00〜16:00 は必ず connected な状態にしてください。
離席が30分を超える場合は Slack のステータスを更新します。

## 備品

- モニタ・椅子の購入補助として、入社時に一律 50,000円
- 通信費は月 3,000円を給与に含めて支給（経費精算は不要）

## 合宿・オフサイト時の扱い

開発合宿など、会社が指定するイベントへの参加日は
リモート日数のカウントに含めません。
