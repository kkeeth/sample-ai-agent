## 社内ネットワーク

社外APIへの通信はプロキシ経由になります。
`HTTPS_PROXY` を設定しないと接続できません。

    export HTTPS_PROXY=http://proxy.example.internal:3128

VPN 接続中はプロキシ設定を外してください。二重に通すと接続が切れます。

## AI関連の基盤

社内から Claude API を利用する場合は、個人のAPIキーではなく
会社アカウントのキーを使ってください。申請は開発基盤チームへ。

利用ログはチーム単位で集計されます。

## トラブルシューティング

- `bun install` が固まる → プロキシ設定を確認
- 401 が返る → キーの有効期限切れ。再発行を依頼
- 429 が返る → レート上限。同時実行数を減らすか、上限引き上げを申請
