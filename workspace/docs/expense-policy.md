# 経費精算ルール

最終改定: 2026-04-01 / 管理部

## 締め切り

当月分の経費は **翌月5営業日以内** に申請してください。これを過ぎた分は
翌々月の精算に回ります。期末（3月）だけは例外で、**3月25日必着**です。

## 申請の流れ

1. 経費精算システム（Workflow）にログイン
2. 領収書を撮影して添付（PDF可、上限10MB）
3. 直属の上長が一次承認
4. 5万円を超える場合は部長の二次承認が必要

アカウントの発行方法は「入社手続きチェックリスト」を参照してください。

## 上限

| 区分 | 上限 | 備考 |
| --- | --- | --- |
| 会食（社内） | 1人あたり 5,000円 | 事前申請が必要 |
| 会食（社外） | 1人あたり 10,000円 | 参加者名簿を添付 |
| 書籍 | 月 20,000円 | 技術書は上限なし |
| 出張宿泊 | 1泊 15,000円 | 都内は 12,000円 |

## よくある差し戻し理由

- 領収書の宛名が個人名になっている（会社名で受け取ること）
- 但し書きが「品代」になっている
- 会食の参加者名簿が添付されていない
