# 障害対応フロー

最終更新: 2026-06-01 / SRE チーム

## 重大度の判定

| レベル | 状態 | 一次対応の期限 |
| --- | --- | --- |
| SEV1 | 全ユーザーがサービスを利用できない | 15分以内 |
| SEV2 | 一部機能が停止、または著しく劣化 | 1時間以内 |
| SEV3 | 軽微な不具合、回避策あり | 翌営業日 |

## 初動

1. `#incident` チャンネルに状況を投稿する（整理してからでなくてよい）
2. インシデント指揮者を1名決める。手を挙げた人でよい
3. SEV1・SEV2 は 15分ごとに状況を更新する

## やってはいけないこと

- 原因究明を優先すること。まず復旧、原因は後
- 指揮者が実作業も兼ねること。指揮に専念する
- 個別DMでのやりとり。すべて `#incident` に残す

## 事後

障害から5営業日以内にポストモーテムを書きます。
個人の責任は追及しません。仕組みの問題として書いてください。
